# Customer Behavior Analysis

## 📊 Project Overview

**Customer Behavior Analysis** is a data analytics project focused on understanding customer purchasing patterns, sales performance, and customer behavior using **SQL, Python, and Power BI**.

The project transforms raw customer transaction data into meaningful insights through data cleaning, exploratory data analysis, SQL-based analysis, and interactive Power BI dashboards.

The main objective is to identify **customer trends, purchasing patterns, sales performance, and business insights** that can help organizations make data-driven decisions.

---

## 🎯 Objectives

* Analyze customer purchasing behavior.
* Identify important customer and sales trends.
* Clean and preprocess raw data.
* Perform data analysis using Python.
* Use SQL to extract meaningful business insights.
* Create interactive dashboards using Power BI.
* Identify patterns that can support business decision-making.

## 🗄️ SQL Analysis

SQL is used to analyze the structured customer data and answer business-related questions such as:

* Which products generate the highest sales?
* Which customer segments contribute the most revenue?
* What are the most frequently purchased products?
* How does customer behavior vary across different categories?
* What are the overall sales trends?
* Which customers or segments have higher purchasing activity?

SQL techniques include:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* `JOIN`
* Aggregate Functions
* Subqueries
* CTEs
* Window Functions

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/Sayalisathe03/Customer_behavior_analysis.git
```

### 2. Navigate to the Project

```bash
cd Customer_behavior_analysis
```

### 3. Install Python Dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Run the Jupyter Notebook

```bash
jupyter notebook
```

Open the Python analysis notebook and run the cells sequentially.

### 5. SQL Analysis

Open the SQL file in your preferred SQL environment and execute the queries against the project dataset.

### 6. Power BI

Open the `.pbix` file using **Microsoft Power BI Desktop** to explore the interactive dashboard.
